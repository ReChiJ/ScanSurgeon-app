# ScanSurgeon

**Align, compare and document 3D surface scans (STL) — on macOS and Windows.**

ScanSurgeon is a lightweight desktop app that aligns and compares 3D surface scans. Load a
master scan and any number of follow-ups, match them with three-point, best-fit (ICP), or
region-based alignment, and instantly see every deviation as a color heat map with full-surface
RMS statistics. Built-in inspection tools measure points, distances, angles, cross-sections, and
even volume differences between overlaid scans — and export everything as aligned STL files, CSV
data, or a clean PDF report with histograms and trend charts across scan series. All processing
happens locally on your machine, so your scan data never leaves your computer.

## Intended use

> Local desktop software for the technical preparation, visualisation, measurement and
> comparative analysis of three-dimensional surface models. Intended for research, teaching,
> presentation, workflow evaluation and technical quality control. Not intended for
> diagnosis, treatment decisions or treatment planning.

**ScanSurgeon is not a medical device.**

## First launch (unsigned app)

The app is not code-signed, so the operating system asks for confirmation the first time:

- **macOS:** right-click the app → **Open** → **Open**.
- **Windows:** **More info** → **Run anyway**.

## Language

The interface is available in **English, German and Chinese (Simplified)** (toggle in the top-right corner).
